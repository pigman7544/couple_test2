# 우리 둘의 이야기 v6.0 — 통합 테스트 웹사이트

사주명리학 계산 + 서양 점성술의 **태양궁**(Swiss Ephemeris 태양 황경) + 선택형 MBTI를 이용하는 문학 커플 스토리텔링 시제품.

## 설치 없는 웹 테스트 (Render)
1. ZIP을 풀어 **안에 있는 파일과 assets 폴더 전체**를 GitHub 저장소 최상위에 올립니다. ZIP 자체를 올리면 안 됩니다.
2. Render의 New Blueprint Instance에서 저장소를 선택하거나, 기존 Render 서비스가 바라보는 브랜치에 파일을 커밋합니다.
3. 배포가 Live가 되면 Render가 제공하는 https://...onrender.com 주소로 접속합니다.
4. 두 사람의 생년월일·시간·양음력·MBTI를 입력하고 전체 레포트 및 백소정·허선 카드 2종을 확인합니다.

## 확인 방법
- `/health` : OK
- `/assets/baek_heo_title.png` : 문구 포함 이미지
- `/assets/baek_heo_plain.png` : 문구 없는 이미지
- 결과 페이지는 결제 없이 전체 레포트를 표시합니다.

## 실제 구현 범위 및 한계
- **사주**: 한국 음양력 변환, 천간·지지, 절기 기반 월주 등 기존 탐색 엔진을 사용. 23시 일주 교체, 지역·경계 시각 등 정밀 검증은 미완료.
- **별자리**: 태양의 황경으로 열두 태양궁을 산출하고, 원소 조합으로 매칭 점수에 최대 3점의 작은 보정을 적용. 달/상승궁/하우스/행성 각도 등을 포함한 전체 출생 차트 분석은 하지 않음.
- **MBTI**: 두 사람 모두 입력한 경우에만 기존 작은 보정 규칙을 적용.
- **문학**: 백소정·허선은 장문 전용 서술 및 그림 2종. 다른 11쌍은 아직 임시 원고, 일러스트 미제작.
- 관계 성향에 대한 과학적 예측이나 심리 진단이 아니라, 전통 상징을 이용한 오락용 스토리텔링 서비스.
- 실제 결제, 계정, 결과 영구 저장 기능은 없음.

## 개발자용 테스트
`pip install -r requirements.txt` 후 `python -m unittest test_v5 test_v6 -v` 및 `python server.py`.

## v6.2 무료 미리보기 / 유료 잠금
- POST /api/match 응답에는 `preview`만 포함합니다. 전체 리포트(`full_report`)는 반환하지 않습니다.
- 5,000원 버튼은 **결제 연동 전 안내용**입니다. 결제되지 않으며 잠금도 해제되지 않습니다.
- 실제 판매 전에는 결제대행사(예: 토스페이먼츠) 서버 승인/서명 검증, 결제 내역 저장, 구매자별 접근 권한, 재열람 기능, 환불/개인정보 안내를 구현해야 합니다. 클라이언트에서 버튼만 눌러 본문을 표시하는 방식은 보안상 사용하지 마세요.
- 카드 이미지는 공개 정적 리소스이므로 실제 유료 제공 시에는 구매자 인증 후 접근 가능한 비공개 경로로 옮겨야 합니다.

## v6.3 결제 버튼 테스트
- 무료 미리보기는 `/api/match`에서 받습니다.
- **5,000원 결제하고 전체 보기 (테스트 무료)** 버튼을 누르면 `/api/test-unlock`을 호출하여 실제 결제 없이 전체 레포트를 표시합니다.
- 테스트용 공개 API이므로 누구나 호출할 수 있습니다. 실제 판매 전 반드시 이 경로를 삭제하고 서버 결제 검증으로 교체하세요.
